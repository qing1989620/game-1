# V6.1 指针港 + 脉冲炉 · 验收记录

> 本文保留该城市开发时的历史基线。当前V6.4开放五城，243项自动化测试；最新第五城验收与限制见 [DUNE_REVIEW.md](DUNE_REVIEW.md)。

日期：2026-10-24，Asia/Shanghai。环境：Windows、Node.js 24.15.0、Chromium 系 Codex 内置浏览器。主界面 1280×720，手机界面使用实际 390×844 浏览器视口覆盖；不等同于手机硬件测试。

## 交付内容

当前开放 **2 / 8 城**。指针港保留事件排序、链路修复与列车返航；脉冲炉增加 WF-01 天气供电、CO-01 进位接线、登塔路线与升降台。支持城际往返、单独重玩第二城、晴雨控制和旧 V6 存档迁移。设计总纲中的 CO-02、CO-03 等后续关卡、其余六城和 ROOT 终章尚未实现。

## 自动验证

- `npm test`：**62 项通过**，其中原有 41 项、新增 21 项。
- 天气测试覆盖开闸漏电、关闸保电、充电与散热阈值、稳态锁存、误操作后的恢复，以及 30/60/120Hz 下相同时间线的结果一致性。
- ALU 测试覆盖 carry 与 zero 的独立含义、边界样例、错误常通电分支。每次 `runCarry` 验证完整的 **256×256=65,536** 组无符号八位加法。
- 存档测试覆盖旧字段迁移、两城往返、未证明的任务阶段、无效设备值和错误证据拒绝。
- 碰撞测试从入城地面连续实走到塔底，无传送、无跌落；无电桥在承重面模型中确实不可通行。
- `npm run build`：严格 TypeScript 检查与生产打包通过。构建器仍提示单个 JS chunk 大于 500KB；实际游戏脚本约 668KB 原始、180KB gzip，CSS 约 45KB 原始、10.6KB gzip。角色概念图只在独立角色卡加载。

## 验收中处理的问题

- 首城新增城际入口最初位于结算页底部，720px 高度下不易发现。已提升为主操作按钮，实际测得按钮位于 y≈531、高52px，完整可见；结算页也支持滚动。
- 第二城重玩时旧结算层曾残留。已在进入章节时统一收起各旧面板，并重置电源、接线和恢复光照。
- 多个同时运行的 3D 验收标签触发过浏览器 WebGL 上下文回收。游戏显示恢复页并保存进度；关闭多余验收页、重载后，从首城检查点继续完成了返航。该中断保留在界面检查记录中，不把中断期间的点击算作规则失败。
- 中断期间日志出现一次 `LineDashedMaterial` 程序校验错误。候选虚线已改成几何线段，复用普通线材质；在独立新页面重新实走到编辑器，验证自环拒绝与正确路线预演，最终没有新增控制台错误。历史日志保留在 JSON 中。
- 本地服务曾随会话中断退出，已重新以隐藏后台生产预览进程提供 5387 端口，并核对 HTTP 200。验收辅助服务在结束后关闭。

## 性能与未验证范围

散热楼体、支撑、甲板栏杆、蒸汽和雨圈尽量采用实例化；第二城首次进入时才创建，当前只渲染一座城市，两场景暂存内存用于往返。验收页帧率来自本机实时测量，不承诺手机达到相同帧率。

尚需安卓/iOS 真机、Safari/Firefox、低端显卡、长时运行和独立新玩家试玩；也未验证所有自由探索角落的相机遮挡。当前天气是玩家可控的游戏系统，没有接入真实天气 API。供电锁存后天气不会破坏已验证的主路。
