六关均使用实际模型执行结果判定。预演可单步或自动播放，场景读取同一运行日志；成功提交后才能改变主线与桥面。任务册支持导航、回看人物故事，以及已扫描站台接驳。支线可以通关后补完，再次乘车不会清空完成记录。

## 六关模型审查

| 关卡 | 错误与有效方案 | 验证边界 |
| --- | --- | --- |
| OS-01 互相等待的人 | 仅改策略不能释放已经拿着的锁；相反首锁存在等待环；两车共同先 A 或共同先 B，加受控重启均通过 | 搜索全部可达有限状态，检查持有双锁后才通过、最后释放；不模拟无限调度空转 |
| OS-02 等不到的电车 | 严格优先级使居民得不到服务；老化间隔 8、同优先级先来先服务通过，间隔过慢可能失败 | 三种背景优先级 8/11/12，各运行 200 周期；两居民到站且背景服务至少 180 周期。并非所有现实调度负载的普遍保证 |
| OS-03 消失的那一票 | 分离读写导致丢票；原子提交、互斥区两种方案均有效 | 两人 6 种、三人 90 种分离读写顺序；有效方案覆盖 2+6 种次序。工人数限制 1–3，拒绝非整数和超限值 |
| OS-04 内存走廊 | FIFO 缺页 11/10/10 超限；命中更新顺序、换出最久端得到 LRU 的 7/6/6 | 三帧、三种负载，第三种中途切换工作集；仅选换出最近端虽可通过前两组，第三组仍以 8>6 失败。没有宣称 LRU 对任意负载都最优 |
| OS-S1 噪声广播 | IF 只检查一次会在货物到达前放行；WHILE 每次醒来重查通过 | 四组情景，包含货物在 0/5/50/90 周期就绪及多次噪声唤醒；将条件检查和进入等待抽象为模型步骤，不涉及真实线程注册通知时的竞争 |
| OS-S2 双重影子 | 分离检查与设置会双占用；CAS 取得权限并按所有者归还可轮流完成 | 2/3 副本全部可达状态；权限在归还前不超时。未实现网络租约到期、进程崩溃恢复或 fencing token |

可达状态搜索使用父节点重建反例，去重并设置 25,000 状态上限；超限会失败而不提交。所有“全部交错”的范围均为本关声明的有限模型，不涵盖现实系统的无限不公平调度。

条件变量的谓词重查与唤醒语义参考 [POSIX condition wait](https://pubs.opengroup.org/onlinepubs/7908799/xsh/pthread_cond_wait.html) 和 [condition broadcast](https://pubs.opengroup.org/onlinepubs/9699919799/functions/pthread_cond_broadcast.html)。原子读改写及比较交换参考 [ECMAScript 2024 Atomics](https://tc39.es/ecma262/2024/multipage/structured-data.html)。游戏使用纯 TypeScript 状态模型讲解这些机制，并未创建真实多线程任务。

## 状态、输入与资源审查

- 领域层独立于 Three.js 和 DOM。提交前同时校验阶段准入、已扫描证据、参数类型与运行证明。补丁以克隆提交；预演、失败实验和退出草案不改权威状态。
- 存档重建已知字段，检查重复/非法关卡、阶段主线前缀、支线前提、已完成策略证明和综合回归状态。完成标签不能绕过模型复算。
- V6 / V6.1 自动补充第三城字段。第二城通关归档经 `parseForge` 校验，且必须依赖首城完成；重玩第二城时保留此记录，避免第三城被已重置的第二城状态锁回去。
- 四主线完成后先做综合回归，再登车；结束和再次乘车都会复核已提交四策略。已完成关卡可以换另一有效解，不重置后续主线；支线不修改主线阶段。
- 城市边界随切换恢复。第三城可走到 z=-190，前两城保留原边界。自动测试沿完整主路及两侧桥走过，锁桥关闭时没有承重面。
- 修正了旧运动控制器在边界外仍站在承重面时，每帧清空复位计时的问题。现在只在合法范围内清空，避免无法触发越界复位。
- 原生 input/select 保留方向键操作，同时让 Escape 和 Tab 进入游戏焦点管理；手机工作台固定底部按钮，预演滚动到执行区，任务册关闭按钮保持在可见顶部，结算可滚动。
- 背景、暂停菜单会冻结第三城模拟和轨迹；恢复时继续同一运行。关闭工作台会清除草案回放，恢复已提交场景。
- 三城按需创建、缓存复用，只渲染当前场景。新设备标牌替换前释放旧 CanvasTexture，执行回放不逐帧创建几何体。短时九轮城际往返中，最后六轮在相同指针港视角均为 390 geom / 35 tex；这不是完整堆内存或长期泄漏证明。
- 运行中不接入账号、遥测或外部 AI API，不执行玩家提供的任意代码。动态报告内容来自有限枚举和数字，不把任意存档字符串插入 HTML。凭据不进入仓库或静态发布目录。
